02 — INSTALLONE COMMAND

From browser
to shell.

The install section stays short. The playground proves the behavior; the command gets out of the way.

npm install -g cxstatusline
cxstatusline install
cxstatusline doctor

cxstatusline installs a patched build matching your supported Codex version; Codex does not currently provide a native statusline extension hook. See the revert procedure.

Close Codex sessions first, then use cxstatusline revert to return to the stock launcher. Start a new Codex session and accept its hook trust prompt. Run cxstatusline to reopen the native editor.

Browser save affects only this browser. Downloading cxstatusline-settings.json does not modify the local CLI.

Transfer a layout

In the native editor, choose Export to save a backup if you want to keep the current layout. Choose Import, enter the downloaded JSON path in Import Config, and press Enter. Inspect Import Preview, then choose Yes at “Apply this preset?”. Confirmation immediately saves and replaces native settings. Choose No or Escape to cancel without applying it.

Questions, answered.

Does this install or change Codex from my browser?

No. The playground is local browser UI; installation is a separate terminal action.

Is the preview live session data?

No. It uses sample data.

Can I run custom commands here?

Native custom commands are supported; this browser demo does not execute them.

Where is my layout saved?

In browser storage for this origin, until cleared. Download it to keep a transferable copy.

Which versions are supported?

See the maintained compatibility documentation.

Is this an official OpenAI product?

No. cxstatusline is an independent project.
